# Tipo de Sistema

La aplicación se ejecutará en un servidor local de la empresa disponible con un sistema cliente-servidor.

Este servidor centralizará la gestión de pedidos y su envío, permitiendo que distintos departamentos de la empresa (logística, finanzas y comercial) accedan al sistema desde sus propios usuarios, mostrando la información relevante para su trabajo.

El servidor local alojará la base de datos y la lógica del programa.

Los usuarios accederán mediante una aplicación de escritorio instalada en sus equipos de trabajo Windows.

Ventajas de un servidor local:

- Varios usuarios trabajan simultáneamente
- Centraliza los datos de pedidos y envíos
- Mejora la seguridad y control al tener una infraestructura propia
- Posibilidad de comunicación API con terceros para futuros desarrollos
- Interfaz más rica y rápida que una app web
