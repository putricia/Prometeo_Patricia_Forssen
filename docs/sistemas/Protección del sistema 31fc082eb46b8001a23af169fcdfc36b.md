# Protección del sistema

Para una seguridad robusta del sistema, contamos con varios métodos en distintas perspectivas y niveles del flujo.

# Seguridad de datos

- Copias de seguridad periódicas programadas
- Credenciales seguras (mínimo 8 caracteres combinando letras, numeros y simbolos)

# Seguridad del servidor

- Firewall activo en el servidor
- Puerto innecesarios cerrados
- Acceso SSH restringido a adminitradores del sistema y equipos autorizados de la empresa
- Actualizaciones periódicas del sistema operativo

# Seguridad web

- Uso de **HTTPS** para cifrar la comunicación entre cliente y servidor
- Validación de datos introducidos por usuarios
- Control de sesiones de usuario

# Control de acceso

- Acceso mediante usuario y contraseña
- Gestión de roles por departamento
- Registro de actividad de usuarios y eventos del sistema en logs
